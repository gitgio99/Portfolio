# E-PowerTrain HILS 상용 4축 차량동역학 제어 로직

## 📌 개요
본 프로젝트는 E-PowerTrain HILS 기반 차량동역학 모델의 시스템 단위 통합 검증 환경 구축을 위한 C-Code API 인터페이스입니다[cite: 2]. 기존 다축 모델을 **상용 4축 모델(8-Wheel)**로 최적화하여 TruckMaker 물리 엔진과 AVL PUMA 다이나모 시스템 간의 실시간 Closed-Loop 연동을 수행합니다[cite: 2]. 본 코드는 시뮬레이션의 물리적 정합성을 맞추고 하드웨어 시험 장비의 손상을 방지하는 핵심 중계 역할을 담당합니다[cite: 1, 2].

## ✨ 주요 기능
* **8륜 수직항력 기반 토크 벡터링 (Torque Vectoring):** 상용 4축 차량의 주행 중 변화하는 각 바퀴의 수직항력(Fz)을 실시간으로 계산하여 최적의 구동 토크를 분배합니다[cite: 1, 2].
* **다이나모 보호 및 램핑(Ramping) 제어:** 토크 변화율을 1ms당 최대 3.0Nm로 제한하고, 다이나모 속도 인가 시 가속도를 최대 650.0 rad/s²로 제한하여 급가감속 시 장비를 보호합니다[cite: 1, 2].
* **스마트 회생 제동 로직:** 가속 페달 해제 시 즉각적인 역토크(-800Nm)를 가동하며, 극저속(0.5m/s 이하)에서는 역토크를 해제하여 승차감을 고려한 부드러운 정차를 구현합니다[cite: 1].
* **HIL / Office 듀얼 모드 지원:** 가상 노이즈 생성 스위치를 통해 실제 모터 테스트 벤치와 유사한 환경을 SILS(Office) 단계에서도 검증할 수 있습니다[cite: 1, 2].

## ⚙️ 시스템 아키텍처 및 인터페이스 매핑
본 로직은 CAN 통신(Msg110, Msg120, Msg220) 기반의 Rest Bus Simulation(RBS) 환경과 연동됩니다[cite: 2]. 

| 통신 방향 | 데이터 명칭 | 설명 | CAN ID / 매핑 |
| :--- | :--- | :--- | :--- |
| **TM ➔ PUMA** | 가속 페달 지령 | TruckMaker 내부 연산 가속 페달 값 | Msg110 / `CM_Gas`[cite: 2] |
| **PUMA ➔ TM** | 실측 토크 피드백 | 다이나모 장비에서 측정된 실제 모터 토크 | Msg220 / `TB_Trq_FL`, `TB_Trq_FR`[cite: 2] |
| **TM ➔ PUMA** | 목표 휠 속도 | 가상 모델에서 산출된 다이나모 목표 회전 속도 | Msg120 / `CM_Rotv_FL`, `CM_Rotv_FR`[cite: 2] |

## 🚀 로직 처리 흐름 (MyLogic_Calc)
1. **입력값 수신:** `DrivMan.Gas` 데이터를 통해 목표 엔진 토크를 설정합니다[cite: 1].
2. **토크 보정 및 제한:** 기어 변속이나 급가속으로 인한 토크 튐 현상을 방지하기 위해 Step 제한 및 회생 제동을 판단하여 `final_trq`를 도출합니다[cite: 1].
3. **토크 분배 (PTXWD Bypass):** 도출된 총 휠 토크를 8개 바퀴의 수직항력(`Car.C<pos>.Frc2C_1.z`) 비율로 나누어 할당합니다[cite: 1].
4. **외력 변환 인가:** 할당된 휠 토크를 타이어 반경(0.4m)으로 나누어 종방향 힘($F_x$)으로 변환한 뒤, 가상 차량의 외부 힘 변수(`Susp_Ext.Frc2CExt_1`)에 직접 대입하여 차량을 구동시킵니다[cite: 1].
5. **속도 피드백:** 구동된 바퀴의 평균 회전 속도를 계산하고, 현재 기어비(`gear_ratio`)를 곱해 PUMA(다이나모) 장비의 목표 엔진 속도로 송출합니다[cite: 1].
