# Portfolio Project Guidelines (Embedded & System Engineer)

## 1. Target & Objective
- **Target Role:** Embedded Software / System Engineer
- **Target Audience:** Technical Recruiters (HR) and Engineering Hiring Managers
- **Objective:** Showcase strong engineering fundamentals (C/C++, Linux, HW control, communication protocols, system architecture) through a clean, multi-language web portfolio.

## 2. Main Content Structure
1. **Header / Hero Section:**
   - Profile summary & core competencies
2. **Core Technical Skills:**
   - Languages: C, C++, Python
   - Embedded Systems & Hardware: MCU, RTOS, Bus Communications (UART, SPI, I2C, CAN, etc.)
   - Systems & Tools: Linux, Network/UDP, Git
3. **Projects Section (Main Focus):**
   - Detailed project cards with:
     * Title, Period, and Key Role
     * Tech Stack Tags
     * Background, Key Features, and Problem-Solution-Result (Troubleshooting)
     * System Architecture / Flowchart image (clickable Modal Lightbox view)
     * GitHub Repository link
4. **Contact Section:** Email, GitHub, LinkedIn, etc.

## 3. General Rules & Tech Stack
- Built with **Pure HTML5, CSS3, and Vanilla JavaScript**.
- Fully **Responsive Web Design** with Dark Mode support.
- Multi-language support using `data-i18n` attributes (Korean & English).
- Focus on general Embedded & System Engineering capabilities without domain-specific bias.
- Keep the interface clean and concise (no resume download buttons or redundant external links).
- Never include proprietary code or confidential assets from former workplaces.
